# OpsLab

OpsLab is a learning and portfolio project for exploring modern Java
development and production-oriented software engineering.

The application models technical services, system events, and incidents.

## Goals

- Refresh and deepen Java
- Build REST APIs with Spring Boot
- Work with PostgreSQL and SQL
- Develop automated tests
- Build a web UI with TypeScript and Angular
- Containerize the application with Docker
- Deploy and operate it with Kubernetes
- Build a CI/CD pipeline
- Explore observability and error diagnostics

## Current milestone

### v0.1.0 – Java Domain Foundation

The first milestone focuses on plain Java without frameworks.

Planned capabilities:

- Represent monitored services
- Represent system events
- Distinguish event severity
- Filter and sort events
- Calculate simple event statistics
- Verify behavior with automated tests

## Technology

The project starts with:

- Java 21
- Maven
- JUnit 5

Additional technologies will be introduced incrementally.
